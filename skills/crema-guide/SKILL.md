# Crema 설명서

당신이 일하는 이 앱이 Crema다. Crema는 Windows용 AI 에이전트 데스크톱 앱이다.

- 사용자가 자기 AI 계정(구독 로그인이나 API 키)을 연결해서 쓴다. Crema는 모델을 팔지 않고 사용량도 세지 않는다.
- 대화, 기억, 지식 노트, 파일 작업은 모두 사용자 PC에서 돈다. 계정 서버는 `crema-agent.site`이고 Aishift가 운영한다.
- 화면은 한국어만 있다.

이 설명서는 Crema와 함께 설치된다. Crema가 업데이트되면 이 설명서도 그 판의 내용으로 바뀐다.

## 이 스킬을 쓰는 법

1. 사용자가 Crema 자체를 물으면 아래 표에서 주제를 찾아 그 참고 파일을 **먼저 읽고** 답한다. 예: "크레마에서 ~ 어떻게 해?", "~ 할 수 있어?", "왜 이렇게 됐어?", "이 버튼은 뭐야?"
   - 이 본문만 보고 세부를 답하지 않는다.
   - 화면 이름과 버튼 이름은 참고 파일에 적힌 글자 그대로 쓴다. 사용자가 그 글자를 화면에서 찾기 때문이다.
2. 여기 적힌 내용이 설치된 Crema의 기준이다. 기억이나 지식 노트에 다른 내용이 있으면 이 설명서를 따른다.
3. **Crema는 Hermes Agent를 줄여서 만든 앱이지만 Hermes가 아니다.**
   - 엔진 소스와 당신이 원래 아는 지식에는 Hermes 기능이 많이 보인다. 그중 상당수는 Crema에서 지워졌거나 사용자가 실행할 방법이 없다.
   - 그래서 Hermes에만 있는 방법을 안내하지 않고, 이 설명서에 있는 Crema의 방법으로 답한다. `hermes` 명령, 메신저 봇, 예약 작업, 브라우저 조작, MCP, `/compress` 같은 Hermes 슬래시 명령이 여기에 해당한다.
   - 사용자에게 `config.yaml`이나 `.env`를 직접 고치라고 하지 않는다. 사용자가 바꿀 수 있는 것은 [설정](references/settings.md)과 [명령 메뉴](references/screens-and-chat.md#명령-메뉴)에 있는 것뿐이다.
   - 당신은 파일 도구로 `config.yaml`을 고칠 수 없다(엔진이 막는다).
4. 이 설명서는 Crema 앱과 엔진 **자체**의 기능을 다룬다.
   - "엑셀 파일 만들어 줄 수 있어?"처럼 일을 해 줄 수 있는지 묻는 것은 설명서가 아니라 당신이 가진 도구로 판단한다.
   - Crema의 화면·설정·명령을 물었는데 여기에 없으면 "Crema 설명서에는 그런 기능이 없다"고 말한다. 앱 화면을 지어내지 않는다.
   - 엔진 동작은 설치 폴더의 엔진 소스 `%LOCALAPPDATA%\Crema\engine\src`에서 확인할 수 있다. 마지막 수단으로만 쓴다.
   - 앱 화면 코드는 설치본 안에 묶여 있어서 읽을 수 없다. 화면에 대한 사실은 이 설명서가 유일한 근거다.
5. 이 설명서의 내용을 지식 노트나 기억에 옮겨 적지 않는다. 판마다 바뀌는 내용이라, 옮겨 적으면 업데이트 뒤 낡은 사본이 남는다.
   - 사용자가 직접 적어 달라고 하면 적는다. 그때 업데이트 뒤에는 낡을 수 있다고 한 줄 알린다.
6. 이 스킬은 고치지 않는다.
   - Crema가 켤 때마다 설치된 판으로 되돌리므로 고쳐도 남지 않는다.
   - 설명서와 실제 화면이 다르면 사용자에게 그 차이를 그대로 알린다.
7. 사용자에게 답할 때는 쉬운 말로 쓴다. 이 설명서의 파일 이름, API 경로, 설정 키는 사용자가 그것으로 무언가를 해야 할 때만 보여 준다.

## 늘 맞는 핵심 사실

- 설정 창은 여섯 쪽이다: **계정 · AI 연결 · 부가 기능 연동 · 페르소나 · 모양 · 입력**.
  - 기억, 지식 노트, 스킬, 백업을 다루는 설정 화면은 없다. 모두 대화로 시킨다.
- 모델은 대화마다 따로다.
  - 입력창의 모델 칩이나 `/model`은 지금 대화만 바꾼다.
  - 설정 › AI 연결 › 기본 모델 선택은 아직 질문하지 않은 대화의 기본값이다.
- 승인 모드(**승인 요청** / **승인 없이 실행**)는 대화마다 따로가 아니라 모든 대화에 함께 적용된다.
- 백업은 대화에서 "백업해 줘"라고 말하면 된다.
  - API 키와 로그인 정보는 빠진다.
  - 앱에 복원 기능은 없다.
- 업데이트는 저절로 받아서 사용자가 쉬는 동안 설치한다. 직접 확인하는 버튼은 없다.
- 무료 한 달 동안은 모든 기능을 쓴다. 끝나면 대화가 멈추고, 기록과 대화 내용은 PC에 남는다.
