# 계정 · 업데이트 · 데이터

## 계정과 요금
- 첫 화면에서 **Google로 시작하기**를 누른다.
  - 브라우저에서 Google 로그인을 마치면 Crema로 돌아온다. 5분 안에 끝내야 한다.
  - Aishift 계정 하나로 Crema와 Thock을 함께 쓴다.
- 로그인 정보는 Windows 자격 증명 관리자에 저장된다.
- 계정 서버에 잠시 연결되지 않아도 마지막으로 받은 계정 정보로 계속 쓴다.
- 처음 로그인하고 엔진이 연결되면 **에이전트 설정**이 한 번 뜬다.
  - 에이전트 이름, 나를 부를 호칭, 말투(존댓말/반말), 바라는 점을 정한다.
  - 건너뛸 수 있다. 나중에 설정 › 페르소나에서 바꾼다.

| 플랜 | 월 요금 | 들어 있는 것 |
|---|---|---|
| 무료 | 0원 | 첫 로그인부터 한 달. 프로와 같은 기능(음성 입력 포함) |
| 기본 | 4,900원 | Crema 전체. 음성 입력 없음 |
| 프로 | 9,900원 | Crema + Thock 음성 입력 |
| 프리미엄 | 14,900원 | Crema + Thock 음성 입력 + 기억 서버 백업(아직 준비 중) |

- 모든 플랜에서 AI 사용료는 연결한 AI 계정에서 따로 나간다.
- 앱 안에서는 아직 결제하거나 플랜을 바꿀 수 없다. 다른 플랜 칸에는 "곧 열립니다"가 보인다.
- 플랜 표시는 사이드바 맨 아래와 설정 › 계정에 있다. 플랜 이름과 끝나는 날이 보인다(예: `기본 · 10월 31일까지`, `무료`).
- **무료 한 달이 끝나면**
  - 앱은 열리고, 대화와 기억은 PC에 그대로 남는다.
  - 입력창 자리에 "무료 기간이 끝났습니다. 플랜을 고르면 이어서 대화할 수 있습니다."와 **플랜 보기**가 나온다.
  - 보내기, 대기열, 대화 깨우기가 모두 멈춘다.
- **로그아웃**: 사이드바 계정 메뉴나 설정 › 계정에서 한다. 대화 기록은 이 PC에 남고, 다시 쓰려면 Google로 다시 로그인한다.

## 업데이트
- 앱을 켜고 1분 뒤, 그 뒤 6시간마다 새 판을 확인한다.
- 새 판은 받아서 내용이 맞는지 확인해 둔다.
- 설치는 아래 조건이 모두 맞을 때 한다.
  - Crema 창에서 5분 동안 키보드·마우스 입력이 없음(다른 프로그램을 쓰는 중이어도 Crema 창이 조용하면 설치할 수 있다)
  - 답하는 중인 대화가 없음
  - 대기열과 입력창이 비어 있음
- 설치할 때 Crema가 꺼졌다가 저절로 다시 켜진다.
- 끝나면 열린 대화에 "업데이트했어요 · Crema x.y.z"가 남는다.
- 직접 업데이트를 확인하는 버튼은 없다. 확인이나 받기에 실패해도 따로 알리지 않고 다음에 다시 시도한다.
- 지금 앱 판을 늘 보여 주는 곳은 없다. `/status`의 "엔진 v…"는 엔진 번호라서 Crema 판(예: 0.2.38)과 다르다.
- 0.2.17 이하 판은 업데이트 주소가 달라서 `https://crema-agent.site/download/`에서 한 번 직접 받아 설치해야 한다.
- Thock은 Crema에 들어 있지 않아 Crema와 따로 업데이트된다([models-and-connections.md](models-and-connections.md#음성-입력)).
- Crema가 업데이트되면 이 설명서도 그 판 내용으로 바뀐다.

## 설치와 제거
- 설치 파일: `https://crema-agent.site/download/`의 `Crema-setup-x64.exe`. Windows만 지원한다.
- 코드 서명이 없어서 "Windows의 PC 보호" 경고가 뜬다. **추가 정보 → 실행**을 누른다.
- 설치하는 동안 Crema가 켜져 있으면 문제가 생길 수 있다. Crema를 끈 뒤 다시 설치한다.
- 설치 위치는 `%LOCALAPPDATA%\Crema`이다. 그 안에 앱과 엔진(`engine\`)이 들어 있다. Thock은 따로 설치된다.
- 제거는 Windows 설정의 앱 목록에서 한다.

## 데이터 저장 위치

| 무엇 | 위치 |
|---|---|
| 앱 데이터 | `%LOCALAPPDATA%\local.agentclient.prototype\` |
| 엔진 폴더 | 위 폴더의 `engine\` |
| 대화 기록(엔진 쪽) | `engine\state.db` |
| 지식 노트 | `engine\knowledge.db` |
| 기억 | `engine\memories\MEMORY.md`(에이전트 메모), `USER.md`(사용자에 대한 기억) |
| 페르소나 | `engine\SOUL.md` |
| 일하는 방법(스킬) | `engine\skills\` |
| API 키 / 구독 로그인 | `engine\.env` / `engine\auth.json` |
| 첨부 파일 사본 | `engine\cache\documents\` |
| 엔진 로그 | `engine\engine.log`, `engine\logs\agent.log`, `engine\logs\errors.log` |
| Thock 데이터 | `%USERPROFILE%\.voicetype\` |
| 대화 목록·화면 설정 | 앱의 WebView 저장소 |
| Crema 로그인 | Windows 자격 증명 관리자 `agent-client` / `crema-account` |
| 받은 업데이트 파일 | `%TEMP%\CremaUpdate\` |

- 에이전트가 이 PC의 파일을 열 때는 터미널에서 `%LOCALAPPDATA%`를 실제 경로로 풀어서 쓴다.
- 사용자에게 엔진 폴더의 파일을 직접 고치라고 하지 않는다. 같은 값을 설정 화면과 앱이 함께 다루므로, 직접 고치면 앱 표시와 어긋나거나 다음 저장 때 덮인다.

## 백업
- 대화에서 "백업해 줘"라고 말한다. 다른 폴더를 말하면 거기에 만든다.
- 기본 위치: `문서\Crema 백업\crema-backup-날짜-시각.zip`. 문서 폴더가 OneDrive로 옮겨져 있으면 그곳을 따른다.
- 들어가는 것: 엔진 쪽 대화 원문, 지식 노트, 기억, 페르소나, 스킬, 엔진 설정(키 값은 지움), 첨부 사본과 만든 그림·영상
- 빠지는 것: API 키, 로그인 정보, 이전 백업, 캐시, 앱의 대화 목록·제목·프로젝트 목록·화면 설정(앱 저장소에 있음), Thock 자료
- 일부 파일을 읽지 못하면 그 부분을 빼고 "불완전"이라고 알린다.
- 앱에는 백업을 되살리는 복원 기능이 없다.
