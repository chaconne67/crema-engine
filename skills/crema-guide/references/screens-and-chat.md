# 화면과 대화

## 창 구성

```
[사이드바] | [앱 바: 사이드바 · 대화 제목 ……… 새 대화 · (설정)]
           | [대화 내용]                                  [미니맵]
           | [입력창 위 칩: 프로젝트 · 이 PC · 브랜치]
           | [대기열]
           | [입력창]
```

- Crema는 한 번에 하나만 켜진다. 다시 실행하면 이미 켜진 창이 앞으로 온다.
- 창을 닫으면 앱이 끝난다. 트레이로 내려가지 않는다.
- 창 위치는 PC를 다시 켜기 전까지 기억한다. PC를 다시 켠 뒤에는 화면 가운데에 뜬다.
- 트레이 아이콘, Windows 알림, Crema 전용 전역 단축키는 없다.

### 앱 바
- **사이드바** 버튼: 사이드바를 접고 편다. 접은 상태는 다음 실행에도 남는다.
- **대화 제목**: 누르거나 **Ctrl+Alt+R**을 누르면 "대화 이름 바꾸기" 창이 뜬다. 최대 40자다.
- **새 대화**: 지금 대화가 비어 있거나 답하는 중이면 눌리지 않는다.
- **설정**(톱니): 사이드바를 접었을 때만 앱 바에 보인다. 평소에는 사이드바 아래쪽 톱니를 쓴다.
- 창 폭이 760px 이하로 좁으면 사이드바가 숨는다. 설정을 열려면 사이드바 버튼을 먼저 누른다.

## 사이드바

- **새 대화**(맨 위): 프로젝트 없는 새 대화를 연다.
- **고정됨**: 고정한 프로젝트와 개별 대화가 모인다. 고정한 항목은 다른 구역에 중복해서 나오지 않는다.
- **프로젝트** + (프로젝트 폴더 추가)
  - 작업할 폴더를 고르면 프로젝트가 된다. 그 프로젝트의 대화는 그 폴더에서 일한다.
  - 이름을 누르면 대화 목록이 접히고 펼쳐진다. 이름에 마우스를 잠시 올리거나 폴더 아이콘을 누르면 **프로젝트 정보**가 열린다. 이름, 보관하지 않은 대화 수, 답변 중인 대화 수(있을 때), 폴더 경로가 보인다. 고정과 **프로젝트 편집**도 여기서 할 수 있다.
  - 프로젝트 줄 오른쪽의 새 대화 아이콘: 이 프로젝트에서 새 대화를 연다.
  - **…** 작업 메뉴:
    - **고정 / 고정 해제**: 프로젝트를 고정됨 구역으로 옮기거나 프로젝트 구역으로 돌린다.
    - **프로젝트 편집**: 화면에 보이는 이름과 폴더 색을 바꾼다. 실제 폴더 이름과 경로는 바뀌지 않는다. 색은 기본·빨강·주황·노랑·초록·청록·파랑·보라·분홍이다. **저장**하면 적용하고, **취소**하면 바꾸지 않는다.
    - **탐색기에서 열기**: 해당 프로젝트의 폴더를 연다.
    - **대화 보관**: 해당 프로젝트에서 보관하지 않은 대화를 전부 보관함으로 옮긴다. 개별 고정 대화도 포함한다. 기록은 남고 진행 중인 답변은 끝까지 간다. 보고 있던 대화를 보관하면 그 프로젝트의 새 대화가 열린다.
    - **프로젝트 제거**: 편집창을 거치지 않고 바로 제거 확인창이 열린다. 폴더와 파일은 남지만 이 프로젝트의 대화 기록(보관함 포함)과 엔진 세션은 **영구 삭제**된다. 확인창에서 취소할 수 있다.
  - 정보창·메뉴·편집창은 바깥 클릭이나 Esc로 닫는다. 메뉴는 위·아래 화살표로 항목을 고르고 Enter로 실행할 수 있다.
- **대화**: 프로젝트에 속하지 않은 대화 목록이다.
- **보관함**: 보관한 대화가 모인다.
  - 줄을 누르거나 **꺼내기**를 누르면 다시 꺼낸다.
  - **영구 삭제**는 보관함에서만 할 수 있다.
  - 보관함 제목 오른쪽의 **모두 삭제**는 보관한 대화를 한꺼번에 영구 삭제한다. 한 번 묻고 지우며, 되돌릴 수 없다. Crema 엔진에 저장된 그 대화들의 세션도 함께 지운다.
- 대화 줄에 마우스를 올리면 **고정 / 고정 해제**, **보관** 버튼이 나온다.
  - 보관해도 진행 중이던 답은 끝까지 간다.
- 대화를 끌어서 프로젝트 위에 놓으면 그 프로젝트로 들어간다. "대화" 구역에 놓으면 프로젝트에서 빠진다. 다음 요청부터 새 폴더에서 일한다.
- 대화 옆 표시

  | 표시 | 뜻 |
  |---|---|
  | 스피너 | 답을 쓰는 중 |
  | 파란 점 | 다른 대화를 보는 동안 새 답이 끝남 |
  | 대기 / 순서 / 차례 / 메시지 | [chats-together.md](chats-together.md) |

- 목록은 최근에 바뀐 순서로 놓인다. 사이드바 검색은 없다. 이름은 앱 바의 제목에서 바꾼다.
- 아무것도 묻지 않은 빈 대화는 다른 대화로 옮기면 저절로 사라진다.
- 오른쪽 경계를 끌면 너비가 바뀐다(200–480px). 경계를 두 번 누르면 기본 너비로 돌아간다.
- 맨 아래 계정 줄을 누르면 메뉴가 열린다: 이메일, **계정**, **로그아웃**. 그 옆 톱니가 **설정**이다.

## 입력창 위 칩

- **프로젝트 칩**: 다른 프로젝트를 고르면 지금 대화를 옮기는 게 아니라 **그 프로젝트의 새 대화**를 연다. **프로젝트 추가…**, **프로젝트 없이 대화**도 여기서 고른다.
- **연결 칩**: 엔진 연결 상태를 보여 준다. "연결 확인 중" → "이 PC" 또는 "연결 안 됨". 누르면 다시 연결한다.
- **브랜치 칩**: 프로젝트 폴더가 Git 저장소일 때만 보인다.
  - 브랜치를 바꾸거나 **새 브랜치 '이름' 만들기**를 할 수 있다.
  - 커밋하지 않은 변경이 있으면 다른 브랜치로는 못 바꾼다. 새 브랜치는 만들 수 있다.

## 입력창

- 안내 글자는 "무엇이든 요청하세요"다. 최대 12,000자까지 쓸 수 있다.
- **Enter** 보내기, **Shift+Enter** 줄바꿈.
- 목록 이어 쓰기
  - `- `, `* `, `• `, `1. `, `1) `로 시작한 줄에서 Shift+Enter를 누르면 다음 항목이 이어진다.
  - 빈 항목에서 누르면 목록이 끝난다. 번호는 저절로 다시 매겨진다.
- 입력창 도구줄
  - **+**: 파일을 첨부한다.
  - **명령 메뉴**
  - **모델 칩**
  - **승인 칩**(방패): [engine.md](engine.md#명령-승인)
  - **마이크**: [models-and-connections.md](models-and-connections.md#음성-입력)
  - **보내기/멈추기**

### 보내기·멈추기는 버튼 하나
- 답하는 중에 입력창이 비어 있으면 **멈추기** 버튼이 된다. 멈춘 답은 받은 데까지 남는다. 그 답이 띄운 백그라운드 작업도 함께 끝난다.
- 그 밖에는 **보내기** 버튼이다.

### 답하는 중에 보내기: 이어서 반영 / 끝나고 반영 / 멈추고 반영
- 답하는 중에 보낸 글은 세 가지 때 중 하나로 들어간다. 답하는 중이 아니면 셋 다 그냥 보내기다.

| 이름 | 키 | 언제 들어가나 |
|---|---|---|
| **이어서 반영** | Enter | 에이전트가 지금 하던 단계(도구 하나)를 마치면 같은 답 안에서 읽는다. 내 말풍선이 들어가고 답이 그 아래 이어진다 |
| **끝나고 반영** | Ctrl+Enter | 지금 답이 다 끝나면 새 요청으로 보낸다. 그때까지 대기열에 있다 |
| **멈추고 반영** | Ctrl+Shift+Enter | 지금 답을 바로 멈추고 이 글을 먼저 보낸다. 대기열에 있던 것은 그다음이다 |

- 키는 답하는 중에 글을 쓰면 입력창 아래에도 보인다.
- **보내기 버튼**을 누르면 버튼 위에 세 가지가 뜬다(이어서 반영이 골라져 있음). ↑↓로 고르고 Enter로 정한다. Esc를 누르면 닫히고 쓴 글은 남는다.
- 답을 막 보낸 직후라 에이전트가 아직 일을 시작하지 않았으면, 이어서 반영한 글은 시작하자마자 들어간다.
- 문서 파일을 붙인 글도 이어서 반영된다(파일은 여느 요청처럼 엔진이 읽는 곳에 저장되고 그 경로가 함께 간다).
- **그림**을 붙인 글은 이어서 반영이 안 된다. 이어서 반영을 골라도 "그림이 붙은 요청은 지금 답이 끝난 뒤에 보냅니다."가 뜨고 끝나고 반영으로 간다.
- 말로 "이건 지금 작업 끝나고 해"라고 보내면 에이전트가 지금 일을 먼저 마친다. 에이전트가 판단하는 일이라 확실히 미루려면 끝나고 반영을 쓴다.
- 이어서 반영한 글을 에이전트가 읽기 전에 답이 끝나면, 그 글은 다음 요청으로 저절로 보낸다.
- **명령 실행 승인 창**("실행해도 될까요")이 떠 있을 때 이어서 반영한 글은 대기열에 "승인 뒤 반영"으로 보인다. 승인 창은 그대로 맨 아래에 남는다.
  - 허용이나 거절을 누르면 그 글이 같은 답 안으로 들어간다. 에이전트는 승인 결정이 끝난 뒤에 그 글을 읽는다.
  - 그래서 글로 "하지 마"라고 써도 명령이 막히지 않는다. 막으려면 **거절**을 누른다.
  - 승인 전에 멈추기를 누르거나 답이 끝나면, 그 글은 다음 요청으로 보낸다.
- 멈추기를 누르면 아직 에이전트에게 전달되지 않은 끼어든 글은 사라진다. 대기열에 있던 글은 남아서 바로 이어 보낸다.

### 대기열
- 입력창 위에 "대기 N개 · 지금 답이 끝나면 차례로 보내요"가 보인다.
- 줄마다 번호, **이어서 반영**(지금 답에 넣기), ×(빼기)가 있다. 승인 창이 떠 있을 때 이어서 반영한 줄에는 "승인 뒤 반영"이 보인다.
- 대기열은 대화마다 따로다. 앱을 닫으면 사라진다.

### 다음 입력 예상
- 답이 끝나면 비어 있는 입력창에 다음에 보낼 만한 말이 흐린 글씨로 보인다.
- **Tab**이나 **→**를 누르면 그 말이 입력창에 들어간다. 보내려면 Enter를 따로 누른다.
- 설정 › 입력 › 다음 입력 예상으로 끈다.
- 답한 모델이 함께 쓰는 것이라 틀릴 수 있다. 답이 오류나 멈춤으로 끝나면 나오지 않는다.

## 명령 메뉴

- 입력창 맨 앞에 `/`를 치거나 명령 메뉴 버튼을 누르면 열린다.
- 한국어 별칭으로도 찾는다.
- 명령 결과는 대화에 잠깐 보이는 줄이고, 대화 기록에는 남지 않는다.

| 명령 (별칭) | 하는 일 | 답하는 중에 |
|---|---|---|
| `/new` (`/새세션`) | 같은 창에서 새 세션을 시작한다. 이전 내용은 보이지만 에이전트는 기억하지 않는다 | 안 됨 |
| `/clear` (`/지우기`) | 이 대화의 화면 기록을 지우고 새 세션을 시작한다. 지운 화면 기록은 되돌릴 수 없다 | 안 됨 |
| `/retry` (`/다시`) | 마지막 질문을 다시 보낸다 | 안 됨 |
| `/stop` (`/중지`) | 진행 중인 답을 멈춘다 | 됨 |
| `/title 새 이름` (`/이름`) | 대화 이름을 바꾼다(40자) | 됨 |
| `/model [이름]` (`/모델`) | 이 대화의 모델을 다음 질문부터 바꾼다 | 됨 |
| `/reasoning [낮음·보통·높음·매우높음·기본]` (`/추론`) | 이 대화의 추론 강도를 바꾼다 | 됨 |
| `/fast [켜기·끄기]` (`/빠르게`) | 빠른 속도를 켜고 끈다. 지원 모델만 되고, 구독 사용량이 더 들 수 있다 | 됨 |
| `/status` (`/상태`) | 연결, 엔진 버전, 모델, 추론 강도, 프로젝트, 이번 세션의 메시지·토큰 수 | 됨 |
| `/usage` (`/사용량`) | 이 대화의 모델 호출 횟수, 토큰, 예상 비용. 구독의 남은 한도는 보여 주지 않는다 | 됨 |
| `/help` (`/도움말`) | 명령 목록 | 됨 |

- 이 표에 있는 명령이 전부다. 다른 에이전트 프로그램에서 쓰는 `/compress`, `/restart`, `/skills` 같은 명령은 Crema에 없다. 표에 없는 `/명령`을 보내면 명령이 아니라 보통 글로 에이전트에게 간다.
- 긴 대화는 자동으로 압축된다: [engine.md](engine.md#대화-압축)

## 첨부

- 넣는 방법
  - **+** › **파일 첨부**
  - **+** › **프로젝트 파일 선택**(프로젝트 대화에서만)
  - 창 위로 끌어다 놓기
  - 그림 붙여넣기(Ctrl+V)
- 그림(png, jpg, gif, webp, bmp)은 원본이 모델에 간다.
  - 파일로 고른 그림은 20MB가 넘으면 첨부할 수 없다.
  - 대화 기록에는 작은 사본만 남는다.
- 그림이 아닌 파일은 엔진 폴더의 `cache\documents`에 복사된다. 에이전트가 그 파일을 직접 읽는다(PDF, Word 등도 글자를 뽑아 읽는다).
- **@ 파일 넣기**: 프로젝트 대화에서 `@글자`를 치면 그 프로젝트의 파일을 찾아 `@상대경로`를 넣는다.
  - `.git`, `node_modules`, `dist`, `build`, `.venv` 같은 폴더는 빠진다.

## 답의 일부를 골라 묻기

- 끝난 답에서 글자를 드래그해 고르면 그 위에 두 가지가 뜬다.
  - **추가 요청**
    1. 입력칸(마이크 포함)이 열린다. 그 부분으로 무엇을 할지 쓰고 Enter(또는 체크 버튼)를 누른다.
    2. 고른 부분은 입력창의 "추가 요청 N개" 칩에 담긴다. 답 안의 그 자리에는 번호가 붙는다.
    3. 보내면 고른 부분이 인용으로, 쓴 말이 그 아래로 들어가 요청 앞에 붙는다.
    - 번호에 마우스를 올리면 쓴 말과 휴지통이 보인다. 칩의 ×는 모두 뺀다.
    - 번호를 누르면 그 부분에 쓴 말이 든 입력칸이 다시 열리고, 그 아래에 휴지통·마이크·취소·저장이 있다. 고쳐서 저장(또는 Enter)하고, 휴지통으로 뺀다. 취소·Esc·바깥을 누르면 그대로 닫힌다.
  - **자세히 물어보기**
    - 오른쪽에 떠 있는 창이 열리고, 지금 대화의 모델이 그 부분을 설명한다. 거기서 계속 물을 수 있다.
    - 이 창의 문답은 대화에 들어가지 않고 에이전트에게도 전달되지 않는다.
    - 도구가 없어서 파일을 바꾸지 못한다. 바꾸게 하려면 추가 요청으로 보낸다.

## 답 화면

### 작업 줄과 일하며 한 말
- 답하는 동안 맨 아래에 작업 줄이 보인다. 지금 하는 일과 걸린 시간이 나온다.
  - 예: 생각 중, 명령 실행 중, 파일 고치는 중, 노트에서 찾는 중, 답변 쓰는 중, 승인 기다리는 중.
- 에이전트가 일하면서 한 말(도구를 쓰기 전에 하는 말)은 작업 줄 위에 차례로 쌓이고, 화면이 따라 올라간다. 생각 요약이 오면 흐린 글씨로 함께 쌓인다.
  - 사용자가 위로 올려 읽고 있으면 화면을 끌어내리지 않는다.
- 답이 끝나면 작업 줄만 사라지고, 쌓인 말은 그대로 남는다. 답 본문은 그 아래, 마지막 도구 다음에 나온 글이다.
- 0.2.39까지 저장된 대화는 쌓인 말이 한 줄씩 보인다(그때는 한 줄로 줄여 저장했다).

### 할 일 목록
- 에이전트가 여러 단계 일을 할 일 목록으로 나눠 진행하면, 답의 맨 위에 체크 목록 상자가 생긴다.
- 에이전트가 목록을 고칠 때마다 상자도 바뀐다.
  - 완료: 체크 표시
  - 진행 중: 도는 표시(답이 끝나면 멈춘다)
  - 대기: 점선 동그라미
  - 취소: 흐린 글자에 줄
  - 하위 항목은 들여 쓴다.
- 답이 끝나도 그 답의 마지막 목록이 남는다. 앱을 다시 켜도 보인다.
- 답하는 중에 이어서 반영으로 글을 넣으면, 목록은 그 글 아래 이어지는 답으로 옮겨 간다.
- 목록을 만들지는 에이전트가 정한다. 짧은 일에는 목록이 없다. 목록으로 해 달라고 말하면 만든다.

### 본문
- 마크다운으로 보인다. 코드 블록에는 **복사** 버튼이 있다. 넓은 표는 옆으로 스크롤된다.
- 답이 나오는 동안 대화는 늘 맨 아래를 따라간다. 사용자가 위로 스크롤하면 그 자리에 머물고, 맨 아래까지 내리면 다시 따라간다. 새 질문을 보내면 맨 아래로 간다.
- 글 안의 HTML은 실행되지 않는다.
- 링크
  - 웹 주소는 기본 브라우저에서 열린다.
  - `.md` 링크는 Crema 문서 보기 창에서 열린다.
- 답 안에 `` `C:\…\파일.docx` ``처럼 인라인 코드로 쓴 Windows 절대 경로는 누르면 열리는 링크가 된다. 옆에 **폴더에서 보기**가 붙는다.
  - 실행 파일(exe, bat, cmd, ps1, js, msi, lnk 등)은 실행하지 않고 폴더에서만 보여 준다.
  - `~\`로 시작하는 경로는 링크가 되지 않는다.
- 에이전트가 한 줄에 `MEDIA:<절대경로>`를 쓰면 그 자리에 그림이 보이거나 영상·소리 재생기가 나온다. 20MB가 넘는 파일은 답 안에 보이지 않을 수 있으니 폴더에서 연다.
- 답이 끝나면 마지막 줄 바로 아래에 끝난 시각과 **답변 복사**가 한 줄로 나온다. 내 질문 아래에는 보낸 시각과 **질문 복사**가 있다. 복사 아이콘에 마우스를 올리면 무엇을 복사하는지 말풍선이 뜬다.

### 답 아래 알림 줄

| 표시 | 언제 | 할 수 있는 일 |
|---|---|---|
| **만든 파일 / 고친 파일 / 바꾼 파일** · 이름 | 이 답에서 에이전트가 쓴 파일(모델과 상관없이 엔진이 기록) | **열기**, **폴더**. 5개가 넘으면 **모두 보기** |
| **기록해뒀어요** · 제목 | 대화가 조용해진 뒤 엔진이 노트·기억에 남긴 것 | 휴지통으로 취소 |
| **일하는 방법을 익혔어요** · 제목 | 정리 중에 스킬을 만들거나 고친 것 | 휴지통으로 취소 |
| **기록해뒀어요** · 대화 중에 기억함 / 노트에 기록함 | 답하는 도중 에이전트가 직접 쓴 것 | 되돌리기 없음 |
| **노트를 정리했어요** · … | 하루 정리 결과 | 없음 |

| **실행해도 될까요** · 설명 — 명령 | 승인이 필요한 명령 | **허용** / **거절** |

- Git 폴더 밖에서 터미널 명령으로 만든 파일은 파일 줄에 나오지 않는다.

### 문서 보기 창
- 답의 `.md` 링크, 경로 링크, 파일 줄의 **열기**를 누르면 Crema 안의 창에서 서식대로 보인다. 같은 폴더의 그림도 함께 보인다.
- 위 줄에 **폴더에서 보기**, **다른 프로그램으로 열기**, ×가 있다. 문서 안의 다른 `.md` 링크로 가면 **뒤로**가 생긴다.
- 보기만 된다. 고치려면 다른 프로그램으로 연다.
- 파일이 바뀌어도 저절로 다시 읽지 않는다. 닫았다 열면 새 내용이 보인다.
- `.md`, `.markdown`만 이 창으로 열린다.

### 대화 제목
- 첫 요청을 보내면 그 대화의 모델이 몇 초 안에 제목을 붙인다.
- 제목이 정해진 뒤에도 답마다 모델이 다시 본다. 요청 횟수와 상관없이, 주된 일이 다른 일로 바뀌었으면 그 답에서 바로 새 제목을 쓴다. 같은 일의 다음 단계나 잠깐 묻는 곁가지 질문이면 그대로 둔다.
- 사용자가 직접 지은 이름(제목 버튼, Ctrl+Alt+R, `/title`)은 다시 바꾸지 않는다.

### 미니맵
- 요청이 2개 이상이면 오른쪽에 요청마다 눈금이 생긴다.
- 마우스를 올리면 앞부분이 보이고, 누르면 그 자리로 간다.
- 창 폭이 600px 이하이면 숨는다.

## 단축키

| 키 | 하는 일 |
|---|---|
| Enter / Shift+Enter | 보내기(답하는 중이면 이어서 반영) / 줄바꿈·목록 이어 쓰기 |
| Ctrl+Enter (답하는 중) | 끝나고 반영 |
| Ctrl+Shift+Enter (답하는 중) | 멈추고 반영 |
| `/` (맨 앞) | 명령 메뉴 |
| `@` (프로젝트 대화) | 프로젝트 파일 넣기 |
| Tab 또는 → (빈 입력창) | 예상 입력 받기 |
| Ctrl+V | 그림 붙여넣어 첨부 |
| Ctrl+Alt+R | 대화 이름 바꾸기 |
| Esc | 그림 보기·문서 보기·메뉴·설정 닫기 |
| CapsLock (Windows 어디서나) | 누르고 말하면 Thock이 받아 적는다(Thock이 켜져 있을 때) |

- Crema의 단축키는 바꿀 수 없다. 받아 적기를 시작하는 키는 Thock 설정(설정 › 입력 › 음성 입력 설정 열기)에서 바꾼다.
