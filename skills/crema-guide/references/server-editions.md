# 서버판: Krema와 Jabis

Crema에는 PC에 설치해 혼자 쓰는 판 말고, 회사 서버에서 도는 판이 둘 있다. 이 설명서의 다른 파일은 PC판 이야기다. 서버판에서 일하고 있다면 이 파일이 먼저다.

| 이름 | 주소 | 누가 쓰는가 |
|---|---|---|
| Krema | `krema.cloud` | 회사의 개발자와 직원 |
| Jabis | `jabis.cloud` | 보험 설계사(FC). 고객을 챙기는 비서 |

## PC판과 다른 점
- 에이전트(엔진)가 사용자 PC가 아니라 서버에서 돈다. 대화도 서버에 저장되어, 같은 계정으로 들어온 모든 기기(브라우저, 휴대폰 홈 화면 앱, PC 앱)에 같은 대화가 보인다.
- 화면의 이름은 Crema가 아니라 Krema 또는 Jabis다. 사용자에게 말할 때 그 이름을 쓴다.
- 로그인은 Google 계정으로 한다. 로그인 화면의 단추는 **Google로 시작하기**다.
  - 권한이 없는 계정으로 들어오면 "○○ 계정에는 Krema(또는 Jabis) 이용 권한이 없습니다."라는 화면이 나오고, 그 화면의 **다른 계정으로 로그인**으로 다시 시작한다. 권한은 운영자(Aishift)가 준다.
- 로그아웃은 설정 › 계정의 **로그아웃**이다. 대화 기록은 지워지지 않는다.

## 계정 등급마다 보이는 것
계정에는 등급이 있고, 등급에 없는 기능은 화면에 아예 나오지 않는다. 사용자가 고르거나 켤 수 있는 것이 아니다.

| 기능 | 개발자 (Krema) | 직원 (Krema) | FC (Jabis) |
|---|---|---|---|
| 대화, 파일 첨부, 알림 | 있음 | 있음 | 있음 |
| 프로젝트, 스킬 | 있음 | 있음 | 없음 |
| 모델 고르기(추론 강도·빠른 속도 포함) | 있음 | 없음 | 없음 |
| 사용량 보기(입력창의 고리, 상태 보기) | 있음 | 없음 | 없음 |
| 서버 폴더를 프로젝트로 붙이기 | 있음 | 없음 | 없음 |

- 직원 계정은 아직 대화를 쓸 수 없다(직원용 에이전트를 준비하는 중이다). 표의 직원 칸은 열렸을 때의 것이다.

## 모델
- 개발자 계정만 모델을 고른다. 방법은 PC판과 같다(입력창의 모델 칩, `/model`).
- 직원과 FC 계정은 서버가 정한 모델로 답한다. 입력창에 모델 칩과 사용량 고리가 없고, 명령 메뉴에 `/model`, `/reasoning`, `/fast`, `/status`, `/usage`가 없다.
  - 이 계정의 사용자가 모델을 바꾸고 싶다고 하면 "이 계정에서는 모델을 고를 수 없다"고 답한다. PC판의 방법(모델 칩, 설정 › AI 연결)을 안내하지 않는다.
  - 모델 이름이나 토큰 수를 먼저 꺼내지 않는다. 화면에도 나오지 않는 것이다.

## 명령 메뉴(`/`)
- 직원·FC 계정: **새 세션** `/new`, **화면 지우기** `/clear`, **다시 시도** `/retry`, **답변 멈추기** `/stop`, **대화 이름 바꾸기** `/title`, **명령어 도움말** `/help`.
- 개발자 계정: 위에 더해 **모델 선택** `/model`, **추론 강도** `/reasoning`, **빠른 속도** `/fast`, **상태 보기** `/status`, **사용량 보기** `/usage`.

## 설정
- 브라우저에서 여는 설정 창은 세 쪽이다: **계정 · 모양 · 입력**.
- PC판에 있는 AI 연결, 지침, 알림 쪽은 서버판에 없다.
- PC 앱으로 열면 **부가 기능 연동** 쪽이 더 보인다. 카톡 보내기, 웹 브라우저 조작처럼 그 PC를 쓰는 기능을 켜는 곳이다.

## Jabis의 화면
- 화면 위(휴대폰에서는 아래)에 **오늘 · 대화 · 고객** 세 탭이 있다.
  - 오늘: 오늘 챙길 일. 없으면 "오늘 챙길 일이 없습니다."와 **대화로 가기**가 나온다.
  - 대화: 비서와의 대화.
  - 고객: 고객 목록과 카톡 친구에서 고객 고르기.

## 서버판에 해당하지 않는 것
PC판 설명서의 아래 내용은 서버판 사용자에게 안내하지 않는다. 물으면 "Krema(또는 Jabis)에는 없다"고 답한다.
- AI 연결(Provider 추가, API 키, 구독 로그인): 모델 연결은 운영자가 서버에 해 둔다.
- 요금제와 무료 기간, 업데이트 버튼, 백업, 설치·제거, 데이터 저장 위치(PC의 폴더).
