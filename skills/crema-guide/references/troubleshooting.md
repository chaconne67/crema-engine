# 문제 해결

사용자가 오류를 말하면 먼저 화면에 뜬 문구를 그대로 받아 아래에서 찾는다. 원인을 알 수 없으면 엔진 로그 `%LOCALAPPDATA%\local.agentclient.prototype\engine\logs\errors.log`와 그 위 `engine` 폴더의 `engine.log`를 읽어 본다. 로그 위치: [account-updates-data.md](account-updates-data.md#데이터-저장-위치)

## 엔진과 연결

| 화면 문구 | 뜻과 할 일 |
|---|---|
| 연결 칩이 "연결 안 됨" / "Crema 엔진을 시작하지 못했습니다. 앱을 다시 시작해 주세요." | 엔진이 켜지지 않았다. 연결 칩을 눌러 다시 연결하고, 안 되면 Crema를 다시 켠다. 새 PC에서 처음 켤 때는 2분까지 걸릴 수 있다 |
| "Crema 엔진이 요청을 거부했습니다." | 앱과 엔진의 연결 정보가 어긋났다. Crema를 다시 켠다 |
| "Crema 엔진이 응답하지 않습니다." / "요청을 처리하지 못했습니다." | 잠시 뒤 다시 시도한다. 계속되면 Crema를 다시 켠다 |
| "응답이 중간에 끊겼습니다." | `/retry`로 다시 보낸다 |

- 엔진이 죽으면 다음 요청 때 Crema가 다시 켠다.

## 답이 오지 않을 때

| 화면 문구 | 뜻과 할 일 |
|---|---|
| "Crema 엔진 응답이 완료되지 않았습니다. (…)" | 모델 쪽에서 실패했다. 괄호 안 문구가 원인이다. 키가 틀림, 로그인 만료, 한도 초과, 모델 이름 오류 등이 흔하다. 설정 › AI 연결에서 그 AI를 다시 연결하거나 다른 모델을 고른다 |
| 모델 메뉴에 "사용할 수 있는 모델이 없습니다" | 연결한 AI가 없다. 설정 › AI 연결 › Provider 추가에서 연결한다 |
| 모델 목록에서 어떤 AI가 사라짐 | 그 AI의 로그인이 만료됐다. Provider 추가에서 다시 연결한다 |
| 입력창 자리에 "무료 기간이 끝났습니다…" | 무료 한 달이 끝났다. **플랜 보기**에서 플랜을 확인한다 |
| `/fast`에 "빠른 속도를 지원하지 않습니다" | 그 모델은 빠른 속도가 없다 |

- 대화가 길어서 느리면 엔진이 자동으로 압축한다. 처음부터 새로 시작하려면 `/new`를 쓴다.

## 웹 브라우저 조작
| 화면 문구 | 뜻과 할 일 |
|---|---|
| "에고 라이트를 설치하지 못했습니다. 다시 눌러 주세요." | 설치 파일을 받지 못했거나, 받은 파일이 Citro Labs의 서명이 아니어서 설치하지 않았거나, 설치 뒤 기본 브라우저의 로그인을 가져오지 못했다. 인터넷 연결을 확인하고 **설치하고 켜기**를 다시 누른다. 에고 라이트 창이 열려 첫 안내를 보여 주면 그 안내를 마친 뒤 다시 누른다 |
| "웹 브라우저 조작을 바꾸지 못했습니다. 다시 눌러 주세요." | 엔진에 켜짐 · 꺼짐을 저장하지 못했다. **켜기** / **끄기**를 다시 누른다. 계속되면 Crema를 다시 켠다 |
| 에고 라이트에 로그인이 안 되어 있음 | 설치 때 기본 브라우저의 기본 프로필만 가져온다. 다른 브라우저나 다른 프로필의 로그인은 에고 라이트의 가져오기 메뉴로 가져오거나 에고 라이트에서 직접 로그인한다 |
| 에이전트가 웹 브라우저 조작을 켜 달라고 함 | 로그인이 필요한 사이트 일인데 웹 브라우저 조작이 꺼져 있거나 에고 라이트가 없다. 설정 › 부가 기능 연동 › 웹 브라우저 조작에서 **켜기**를 누른다 |
| 에이전트가 로그인해 달라고 함 | 그 사이트에 에고 라이트로 로그인한 적이 없거나 로그인이 풀렸다. 에고 라이트에서 로그인하고 대화로 알려 준다 |

## 메일 연결

| 화면 문구 | 뜻과 할 일 |
|---|---|
| 안내에 "메일이 아직 로그인을 받지 않아요. 메일 설정에서 IMAP을 ‘사용함’으로 저장해 주세요" | 메일 회사가 앱 비밀번호 로그인을 거절했다. 대개 IMAP이 꺼져 있어서다. 안내가 묻는 대로 메일 설정으로 가서 IMAP을 "사용함"으로 저장하고 **Crema에 넣기**를 누른다. 그래도 안 되면 안내를 닫고 처음부터 다시 연결해 새 앱 비밀번호를 만든다 |
| 안내에 "메일 서버에 닿지 못했어요…" | 인터넷 연결을 확인하고 **Crema에 넣기**를 다시 누른다 |
| 메일 연결 중 휴대폰 확인 알림이 오지 않음 | 확인 알림은 메일 회사가 휴대폰 앱(네이버는 네이버 앱)으로 보낸다. 그 앱의 알림이 꺼져 있으면 오지 않는다. 휴대폰 설정과 그 앱 설정에서 알림을 켜고, 그 앱을 직접 열어 확인 요청이 와 있는지 본다. 화면의 「알림 다시 보내기」로 다시 받을 수 있다 |
| 대화창에 "다음에 할 일을 살펴보고 있어요…"가 뜸 | Crema가 화면을 보고 다음에 물을 것을 정하는 중이다. 보통 몇 초 안에 나온다 |
| 사이트 화면을 눌러도 아무 일이 없음 | 사이트 화면은 보기만 한다. 대화창의 단추를 고르거나 입력칸에 적는다. 로봇 확인처럼 사람만 할 수 있는 일은 안내가 그때 화면을 풀어 준다("직접 하는 중") |
| "화면에서 하고 있어요…"에서 오래 멈춤 | Crema가 누른 뒤 화면이 아직 바뀌거나 불러오는 중이다. 화면이 멈추면 이어서 안내한다. 계속 멈춰 있으면 안내를 닫고 다시 연결한다 |
| 직접 했는데 다음 안내가 안 나옴 | 화면이 풀려 직접 하는 일은 **다 했어요**를 눌러야 다음으로 간다 |
| 안내에 "안내 요청이 너무 많았어요…" | 한 시간에 부를 수 있는 안내 횟수를 넘었다. 잠시 뒤 **다시 해 보기**를 누른다 |
| 안내에 "안내를 불러오지 못했어요…" | crema-agent.site에 닿지 못했다. 인터넷 연결을 확인하고 **다시 해 보기**를 누른다 |
| "지금은 지메일·네이버·다음·카카오 메일을 연결할 수 있습니다." | 그 밖의 메일은 아직 연결할 수 없다 |
| "아웃룩은 곧 로그인만으로 연결할 수 있게 됩니다." | 아웃룩·핫메일은 아직 안 된다 |
| 구글 연결 뒤 설정에 "구글 화면에서 … 권한을 체크하지 않아 연결하지 않았습니다" | 허용 화면에서 그 기능의 권한 체크를 빼고 허용했다. 다시 **연결**을 누르고 허용 화면에서 체크한다 |
| 구글 연결 뒤 설정에 "다른 구글 계정으로 허용하셨습니다" | 다른 계정을 골랐다. 다시 연결해 지메일은 넣은 주소의 계정, 캘린더·드라이브는 전에 Crema에 연결한 구글 계정을 고른다 |
| 구글 연결 중 브라우저 창을 닫았거나 허용 화면이 안 보임 | 설정의 그 줄에서 **취소**를 누르고 **연결**을 다시 누른다. 기본 브라우저에 다시 열린다 |
| 구글 허용 화면에 "Google에서 확인하지 않은 앱" | 구글의 Crema 앱 심사가 끝나기 전에 나오는 경고다. **고급** → **Crema(으)로 이동**을 누른다 |
| 구글 허용 화면에 "차단된 앱"·"액세스 차단됨"·"이 앱은 차단됨" | 회사 구글 계정이면 관리자가 외부 앱을 막았을 수 있다. 관리자에게 Crema 허용을 부탁하거나 개인 구글 계정으로 연결한다. 개인 계정인데 지메일에서 나오면, 구글이 Crema 앱 심사를 마치기 전이라 지메일 권한을 막은 것이다. 설정의 그 줄에서 **취소**를 누르고 심사가 끝난 뒤 다시 연결한다. 그 밖의 경우는 Aishift에 알린다 |
| 지메일이 연결됨인데 에이전트가 "Google no longer lets Crema in"이라고 함 | 구글 계정에서 Crema 허용을 거두었거나 구글이 로그인을 끊었다. **연결 끊기** 뒤 다시 연결한다 |
| 연결됨인데 에이전트가 "로그인을 거절했다"고 함 | 앱 비밀번호를 지웠거나 바꿨다. **연결 끊기** 뒤 새 앱 비밀번호로 다시 연결한다 |
| 에이전트가 "메일을 보내지 않았다"고 함 | 보내기 승인 창에서 거절했거나 5분 안에 답하지 않았다. 보내려면 다시 부탁한다 |
| 에이전트가 참석자 있는 일정을 "하지 않았다"고 함 | 일정 초대·변경·취소 알림 승인 창에서 거절했거나 5분 안에 답하지 않았다. 하려면 다시 부탁한다 |

## 컴퓨터 조작

| "말을 받아 적기 시작하지 못했습니다. Crema를 다시 켜 주세요." | Crema를 다시 켠다 |
| "Thock 설정 창을 열지 못했습니다. Crema를 다시 켜 주세요." | Crema를 다시 켠다 |
| 마이크 버튼이 안 보임 | 엔진이 아직 연결되지 않았다. 연결 칩이 "이 PC"가 될 때까지 기다린다 |

## 승인과 명령
- "이미 끝났거나 시간이 지난 요청입니다.": 그 승인 요청은 이미 끝났다. 필요하면 다시 시킨다.
- 에이전트가 명령마다 묻는 게 번거로우면 방패 칩에서 **승인 없이 실행**을 고를 수 있다. 다만 모든 명령이 묻지 않고 실행된다는 점을 함께 알린다.

## 다른 대화가 기다리고 있을 때
- 사이드바에 "대기", "순서"가 보이면 두 대화가 같은 파일을 고치려는 중이다. 그 대화를 열어 카드의 버튼으로 순서를 정한다: [chats-together.md](chats-together.md)

## 업데이트가 안 될 때
- 설치는 5분 동안 조작이 없고 답과 대기열이 비어 있을 때만 한다. 계속 쓰는 중이면 미뤄진다.
- 0.2.17 이하에서는 저절로 업데이트되지 않는다. `https://crema-agent.site/download/`에서 받아 설치한다.

## 알 수 없을 때
- 이 설명서와 로그로도 원인을 모르면 추측하지 않는다. 확인한 것과 모르는 것을 나눠 사용자에게 말한다.
