# 문제 해결

사용자가 오류를 말하면 먼저 화면에 뜬 문구를 그대로 받아 아래에서 찾는다. 원인을 알 수 없으면 엔진 로그 `%LOCALAPPDATA%\local.agentclient.prototype\engine\logs\errors.log`와 그 위 `engine` 폴더의 `engine.log`를 읽어 본다. 로그 위치: [account-updates-data.md](account-updates-data.md#데이터-저장-위치)

## 엔진과 연결

| 화면 문구 | 뜻과 할 일 |
|---|---|
| 연결 칩이 "연결 안 됨" / "Crema 엔진을 시작하지 못했습니다. 앱을 다시 시작해 주세요." | 엔진이 켜지지 않았다. 연결 칩을 눌러 다시 연결하고, 안 되면 Crema를 다시 켠다. 새 PC에서 처음 켤 때는 2분까지 걸릴 수 있다 |
| "Crema 엔진이 요청을 거부했습니다." | 앱과 엔진의 연결 정보가 어긋났다. Crema를 다시 켠다 |
| "Crema 엔진이 응답하지 않습니다." / "요청을 처리하지 못했습니다." | 잠시 뒤 다시 시도한다. 계속되면 Crema를 다시 켠다 |
| "응답이 중간에 끊겼습니다." | `/retry`로 다시 보낸다 |

- 엔진이 죽으면 다음 요청 때 Crema가 다시 켠다.

## 답이 오지 않을 때

| 화면 문구 | 뜻과 할 일 |
|---|---|
| "Crema 엔진 응답이 완료되지 않았습니다. (…)" | 모델 쪽에서 실패했다. 괄호 안 문구가 원인이다. 키가 틀림, 로그인 만료, 한도 초과, 모델 이름 오류 등이 흔하다. 설정 › AI 연결에서 그 AI를 다시 연결하거나 다른 모델을 고른다 |
| 모델 메뉴에 "사용할 수 있는 모델이 없습니다" | 연결한 AI가 없다. 설정 › AI 연결 › Provider 추가에서 연결한다 |
| 모델 목록에서 어떤 AI가 사라짐 | 그 AI의 로그인이 만료됐다. Provider 추가에서 다시 연결한다 |
| 입력창 자리에 "무료 기간이 끝났습니다…" | 무료 한 달이 끝났다. **플랜 보기**에서 플랜을 확인한다 |
| `/fast`에 "빠른 속도를 지원하지 않습니다" | 그 모델은 빠른 속도가 없다 |

- 대화가 길어서 느리면 엔진이 자동으로 압축한다. 처음부터 새로 시작하려면 `/new`를 쓴다.

## 계정과 로그인

| 화면 문구 | 뜻과 할 일 |
|---|---|
| "5분 안에 로그인이 끝나지 않았습니다." | **Google로 시작하기**를 다시 누르고 5분 안에 마친다 |
| "crema-agent.site에 연결하지 못했습니다." | 인터넷 연결을 확인한다. 이미 로그인한 상태면 앱은 계속 쓸 수 있다 |
| "Windows 자격 증명 관리자에 접근하지 못했습니다." | Windows 자격 증명 관리자가 막혀 있다. PC를 다시 켜 본다 |

## 파일과 첨부

| 화면 문구 | 뜻과 할 일 |
|---|---|
| "20MB보다 큰 이미지는 첨부할 수 없습니다." | 그림을 줄이거나 파일 경로를 글로 알려 준다 |
| "첨부 파일을 준비하지 못했습니다." | 보내려던 글과 첨부는 입력창으로 돌아온다. 다시 보낸다 |
| "파일이 그 위치에 없습니다. 옮겨졌거나 지워졌을 수 있습니다." | 파일이 옮겨졌다. 에이전트에게 다시 찾게 한다 |
| "문서를 읽지 못했어요." | 문서 보기 창에서 그 파일을 못 읽었다. **다른 프로그램으로 열기**를 쓴다 |
| "커밋하지 않은 변경이 있어 브랜치를 바꾸지 않았습니다." | 커밋하거나 새 브랜치를 만든다 |
| "대화 기록을 읽거나 저장하지 못했습니다…" | 디스크 공간과 권한을 확인한다. 이 상태에서 앱을 닫으면 최근 변경이 사라질 수 있다 |

## 음성 입력

| 화면 문구 | 뜻과 할 일 |
|---|---|
| "음성 입력을 쓰려면 받아쓰기 서비스를 연결해야 합니다…" | 플랜에 음성이 없을 때 쓰는 엔진 받아쓰기에 연결된 서비스가 없다. 설정 › AI 연결 › Provider 추가에서 Groq(무료 키)나 OpenAI·xAI API 키를 연결한다 |
| "Crema가 마이크를 쓸 수 없습니다…" | Windows 설정 › 개인 정보 › 마이크에서 마이크 권한을 켠다 |
| "들린 말이 없습니다. 마이크 버튼을 다시 누르고 말씀해 주세요." | 마이크 버튼을 다시 누르고, 마이크에 가까이 말한다 |
| "말씀하신 내용을 받아 적지 못했습니다…" | 받아쓰기 서비스가 답하지 않았다. 마이크 버튼을 다시 누르고 말한다 |
| "Crema 안의 음성 입력을 켜지 못했습니다…" | 따로 설치한 Thock이 있으면 Thock을 최신 판으로 업데이트한다. 그동안은 CapsLock을 누르면 따로 설치한 Thock이 받아 적는다. 따로 설치한 Thock이 없으면 Crema를 다시 켠다 |
| "음성 입력을 시작하지 못했습니다. Crema를 다시 켜 주세요." | Crema를 다시 켠다 |
| 마이크 버튼이 안 보임 | 엔진이 아직 연결되지 않았다. 연결 칩이 "이 PC"가 될 때까지 기다린다 |

## 승인과 명령
- "이미 끝났거나 시간이 지난 요청입니다.": 그 승인 요청은 이미 끝났다. 필요하면 다시 시킨다.
- 에이전트가 명령마다 묻는 게 번거로우면 방패 칩에서 **승인 없이 실행**을 고를 수 있다. 다만 모든 명령이 묻지 않고 실행된다는 점을 함께 알린다.

## 다른 대화가 기다리고 있을 때
- 사이드바에 "대기", "순서"가 보이면 두 대화가 같은 파일을 고치려는 중이다. 그 대화를 열어 카드의 버튼으로 순서를 정한다: [chats-together.md](chats-together.md)

## 업데이트가 안 될 때
- 설치는 5분 동안 조작이 없고 답과 대기열이 비어 있을 때만 한다. 계속 쓰는 중이면 미뤄진다.
- 0.2.17 이하에서는 저절로 업데이트되지 않는다. `https://crema-agent.site/download/`에서 받아 설치한다.

## 알 수 없을 때
- 이 설명서와 로그로도 원인을 모르면 추측하지 않는다. 확인한 것과 모르는 것을 나눠 사용자에게 말한다.
