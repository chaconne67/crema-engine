# 발표 PDF

사용자의 원고와 목적에 맞춰 장별 내용을 먼저 구성한다. 장수 요구가 있으면 각 장의 역할을 정하고 본문을 누락하지 않는다.

서버의 `pdf_save`가 정적 HTML을 Chromium으로 출력한다. 출력은 A4이며 위아래 16mm, 좌우 14mm 여백 안에 각 장의 내용을 배치한다. 한 장을 한 페이지로 구성하고 마지막 장 외에 `break-after:page`를 쓴다. 다른 종이 크기를 요청받으면 이 도구의 A4 출력 범위를 먼저 알린다. 외부 스크립트·그림 URL·로컬 파일은 읽지 않으므로 필요한 그림은 `data:`로 넣는다.

PDF를 `document_read`로 다시 읽어 장수·원고·표를 확인하고 파일 링크를 준다. 시각 검토가 필요하면 PDF 쪽 그림을 보고 글 잘림·넘침을 확인한다. 출력 실패나 빠진 페이지를 성공으로 보고하지 않는다.
